操作指南

亚马逊批量广告
生成工具

把 Excel 广告框架一键转成亚马逊 SP（商品推广）批量上传文件，并自动按机型 / 产品 / 搜索词追加否定关键词。

注意：本工具仅生成 SP 商品推广。若框架里混入了 SB / SBV（品牌推广）等活动，会被自动识别并跳过，不写入结果文件（可在日志与复核报告查看被跳过的活动）。

02

前期准备

广告框架文件
必填

在网页「模板下载」区点 下载广告框架，得到 广告框架模板.xlsx（与示例模板一致）。固定表头不要修改，按第 03 章规范填写后上传。

否词表
可选

在「模板下载」区点 下载否词模板，得到 否词模板.xlsx，内含「机型否词 / 按产品否词 / 精准否词」三类工作表。结构见第 05 章。

提示 「模板下载」区有两个独立按钮：下载广告框架 与 下载否词模板，分别输出两份不同的文件，不要混淆。
03

填写模板（广告框架）

模板按表头名称识别列，列的位置可自由调整。下表为下载到的 广告框架模板.xlsx 实际列。

列名必填说明
Campaign必填广告活动名称。含 PAT 视为商品投放；工具从中提取机型 / 产品，用于自动匹配否词。
广告类型必填填 SP（Sponsored Products 商品推广），当前仅支持 SP。填 SB / SBV / SBD 等品牌推广活动会被自动识别并跳过，不生成。
匹配类型必填决定广告类型与匹配方式，取值见第 04 章（EM / BM / PM / AUTO / PAT / 空）。建议始终明确填写，不要留空。
投放词必填*关键词：每行一词。
商品投放：填 asin="B0XXX" 做单品定投，或填 category="类目ID" 做类目投放（一行一个目标，详见第 04 章）。
自动广告：填 紧密 / 宽泛 / 同类 / 关联，每词一行；留空则四类全开。
SKU必填推广的商品 SKU，多个换行分隔。
ASIN必填被推广 ASIN（B0XXX）；需要跟SKU对应。
广告组必填广告组名称。
预算必填每日预算。
竞价必填单次出价。可分别填写（见第 04 章）。
tos%可选搜索结果顶部加价（0–900）。
否定（仅NP）可选本行自带的词组否定词（默认词组否定 NP）。
续行 同一 Campaign 可写多行：第一行写 Campaign 名称，后续行留空 Campaign 即自动合并到上一行。
辅助列 序号、预估日均click、预估广告日销、note、广告创建checklist、开启checklist 等为辅助 / 自检列，可留空，不影响生成。
04

匹配规则

匹配类型

匹配类型列广告类型匹配方式
AUTO / 自动自动广告不生成关键词，按「投放词」列出的类型开启
EM / 精准手动关键词exact
BM / 广泛手动关键词broad
PM / 词组手动关键词phrase
PAT / 商品投放商品投放Product Targeting
空 / 其它手动关键词默认 exact（建议始终明确填 EM / BM / PM）
匹配类型 始终明确填写 EM / BM / PM，避免依赖默认行为；BM 即广泛、EM 即精准、PM 即词组。关键词中不再使用 + 来代表广泛匹配。

商品投放（PAT）

  • 识别：Campaign 含 PAT，或匹配类型写 PAT / 商品投放。
  • 投放词填投放目标表达式，每行一个：
    • 单品定投：asin="B0XXX"（也可只写裸 ASIN B0XXX，工具会自动补引号）。
    • 类目投放：category="类目ID"。类目ID 是数字，需在亚马逊后台「商品投放 → 选择类目」后复制表达式里的数字（如 category="2335753011"）。
  • 生成 Product Targeting 行，不会生成关键词。
类目投放注意 ① category= 后必须填亚马逊「类目ID」数字，不要直接填中文类目名（如 category="手机壳" 会导入失败）。
② 建议带英文引号 "，对齐官方批量文件格式。
③ 一个广告组可写多行 category= 投多个类目；类目还能加细化条件，写成 category="类目ID" with refinements(...)。
④ 商品投放行的「投放词」不要混普通关键词，否则会被当成表达式报错。
注意 商品投放的「投放词」为空时，只建框架、不生成投放行。

自动广告的四种投放类型

在「投放词」列按换行填写要开启的类型，未列出的自动暂停。留空则四类全开。

投放词亚马逊类型含义
紧密 / 紧密匹配close-match搜索词与商品高度相关
宽泛 / 宽泛匹配loose-match搜索词与商品松散相关
同类 / 同类商品substitutes相似 / 竞品商品详情页
关联 / 关联商品complements互补商品详情页

不同出价

  • 匹配类型填 AUTO，在「竞价」列对每个类型单独写出价，需确保在同一行。
  • 多个类型换行填写，各类型可设不同出价；未写出的类型默认不开启。
05

否词模板

下载得到的 否词模板.xlsx 含 6 个工作表：18否词 / 18air否词 / 18pro否词 / 18pm否词（机型否词），按产品否词，精准否词。按表名自动识别类型，上传后工具会按规则追加到对应广告活动。

两种否定方式 NP = 词组否定（negativePhrase）：搜索词包含该词组即否定。
NE = 精准否定（negativeExact）：搜索词完全等于该词才否定。

① 机型否词（4 个表）

每个表对应一个 iPhone 机型，表名含「否词」即识别为机型否词。

  • 第一行：A1 写表头「否定机型」；B1 写机型名，例如 iPhone 18 Pro Max（需与广告名能匹配）。
  • A列：否定关键词；B列：否定类型 NP 或 NE。
如何被应用 工具从 Campaign 名提取机型（如 iPhone18PM → iPhone 18 Pro Max），与表内机型名做模糊匹配（子集匹配，18PM 可命中「iPhone 18 Pro Max」）。命中后，该表所有词加为对应类型否定词。

② 按产品否词（1 个表）

按产品代号 / 系列否定，只有广告名包含该产品的活动才会应用。

  • 第一行：A1 写表头「关键词」；B1 起写产品代号，例如 GHMSBH（即广告名里的产品代码）。
  • A列：否定关键词；B列（及后续列）：各产品代号下的 NP / NE。
如何被应用 若 Campaign / 广告组名包含该产品代号（如 SPP_iPhone17_GHMSBH_SP_DC_EM 中的 GHMSBH），则该词加为对应类型否定词。也支持填系列全称（通过全称 ↔ 代码映射命中）。

③ 精准否词（1 个表）

全局否定，每个广告活动都会追加。

  • 第一行：A1 写表头「搜索词」；B1 写表头「否定类型」。
  • A列：搜索词；B列：NE（精准否定）。
上传后核对 上传否词表后，日志会显示「机型否词 X 个机型 / 按产品否词 X 个产品 / 精准否词 X 个」；生成时每条记录还会打印「应用机型否词(NP, iPhone 18 Pro Max): N个」等，据此确认是否生效。
06

操作步骤

1

下载模板

在「模板下载」区点 下载广告框架 得 广告框架模板.xlsx 并填好；如需否定词，点 下载否词模板 得 否词模板.xlsx 并按第 05 章填写。

2

上传文件

上传广告框架文件；如需否定词，再上传否词表（同样支持 .xlsx / .xls）。

3

生成并下载

点「生成广告模板」，检查日志是否有红 / 黄色提示；否词应用数量会在日志中显示。

07

常见问题

匹配类型 BM 就是广泛匹配吗？

是。匹配类型列填 BM 即 broad 广泛匹配；EM 为 exact 精准、PM 为 phrase 词组。无需在关键词里加 +。

商品投放为什么生成失败？

投放词为空或表达式格式不对。在「投放词」列填 asin="B0XXX" 或 category="类目ID" 即可（详见第 04 章「商品投放」）。

关键词匹配方式不对？

检查匹配类型是否写了 BM（广泛）/ EM（精准）/ PM（词组）。匹配类型列留空时，默认按 exact 精准处理。

自动广告怎么只开部分类型？

匹配类型填 AUTO，在「投放词」列写要开启的类型，如 紧密、关联。留空则全开。

上传后提示「缺少某列」？

表头名称与要求不符。按第 03 章列名核对（识别看列名，不看位置）。

否词模板的三类表有什么区别？

机型否词按机型命中（Campaign 名里的机型）；按产品否词按产品代号命中（Campaign 名里的代码，如 GHMSBH）；精准否词全局生效，所有活动都加。

机型否词的机型名怎么填才匹配？

按标准写法，如 iPhone 18 Pro Max、iPhone 18、iPhone 18 air、iPhone 18 Pro。工具用模糊子集匹配，18PM 也能命中「iPhone 18 Pro Max」。

NP 和 NE 该怎么选？

想更宽松地拦截（只要搜索词里出现该词组就否定）用 NP；只想精确拦截完全一致的搜索词用 NE。

类目投放怎么写？

匹配类型列填 商品投放（或 Campaign 名含 PAT），「投放词」列填 category="类目ID"（类目ID 从后台商品投放选类目后复制）。一行一个类目，可写多行投多个类目；不要填中文类目名，也不要与关键词混填。单品定投则填 asin="B0XXX"。

为什么 SB 广告没出现在结果里？

本工具只生成 SP 商品推广，SB / SBV 品牌推广会被自动跳过。被跳过的活动会在生成日志（黄色提示）和复核报告的「跳过记录」中列出，可据此核对。

08

注意事项

  • 匹配类型按行生效：同一行的投放词共用同一种匹配方式，建议始终明确填写 EM / BM / PM。
  • 商品投放务必填投放词：否则只建空框架。
  • 自动广告留空即全开：填了类型则只开启列出的，其余暂停。
  • 否词表表名决定类型：含「按产品」→ 按产品否词；含「精准」→ 精准否词；含「否词」→ 机型否词。改名会导致识别错误。
  • 否词上传后看日志：确认「机型 / 按产品 / 精准」三类否词的应用数量，避免漏配。
  • 仅生成 SP：SB / SBV 等品牌推广活动会被自动识别并跳过，不会写入批量文件；生成日志与复核报告会列出被跳过的活动，便于核对。
